# 1차 개선 XGBoost의 2024년 예측 및 평가 결과

이 문서는 기본 XGBoost, 개선 XGBoost V1, 팀원 앙상블 V2의 저장된 예측 결과를 비교합니다. 개선 XGBoost V1의 총 모의 벌금은 **2,000,275.63원**입니다.

평가 대상과 표본 수는 다음과 같이 구분합니다.

| 평가 항목 | 대상 |
|---|---|
| 예측 파일 생성 | 2024년 전체 8,784시간, G1/G2 합계 17,568행 |
| 모의 벌금 | 253개 발전소의 실제 발전량이 모두 있는 178시간 |
| MAE·RMSE·WAPE | 2024년 전체 유효 관측값 1,884,185개 |

**178시간의 모의 벌금은 2024년 전체 연간 벌금이나 공식 대회 서버의 점수가 아닙니다.** 실제 발전량의 결측값을 0이나 예측값으로 대체하지 않았습니다. 이번 문서 수정에서는 모델 코드, CSV, 학습 결과와 예측값을 변경하지 않았습니다.

## 1. 모델과 학습 방법

`xgboost_comparison.py`는 개선 XGBoost V1을 학습하고 예측한 원본 코드의 복사본입니다. 이 코드에는 기본 XGBoost와 LightGBM의 비교 과정도 포함되어 있습니다. 문서와 비교표를 정리하기 위해 모델을 재학습하지 않았습니다.

2022년 자료로 초기 모델을 학습하고, 2023년 검증 자료로 하이퍼파라미터와 트리 개수를 선택했습니다. 선택한 설정을 고정한 뒤 2022~2023년 자료로 최종 모델을 학습했습니다. 2024년 실제 발전량은 최종 평가에만 사용했으며, 평가 결과를 보고 설정을 다시 조정하지 않았습니다.

10시 예보와 17시 예보에 대해 각각 모델을 학습하고, 두 모델의 예측 발전량을 평균했습니다. 초기 학습의 마감 시각은 각각 2022-12-31 10:00 및 17:00 KST이며, 최종 학습의 마감 시각은 각각 2023-12-31 10:00 및 17:00 KST입니다.

모델은 발전량을 설비용량으로 나눈 설비이용률을 학습합니다. 학습 목표값은 [0, 1.2] 범위로 제한하고, 예측한 설비이용률에 설비용량을 곱해 발전량으로 환산합니다. 예측 발전량은 비음수로 제한하며, 태양 고도가 0 이하인 야간에는 0으로 처리합니다. 이 야간 예측 처리는 실제 발전량의 결측값을 대체하는 것과 다릅니다.

추가 입력 특징은 발전소 코드, 기상 제공사 간 운량·기온 차이, 기온과 이슬점의 차이, 태양 위치와 운량·자외선 지수의 상호작용, 제공사 B의 풍속을 m/s로 환산한 값입니다.

### 선택된 XGBoost 설정

아래 파라미터 이름은 실제 Python 코드의 `XGBRegressor` 인자와 일치합니다. 난수 설정은 `seed`라는 별도 인자가 아니라 **`random_state=42`**로 전달됩니다.

| 파라미터 | 값 또는 사용 방법 |
|---|---|
| `max_depth` | 6 |
| `learning_rate` | 0.03 |
| `subsample` | 0.8 |
| `colsample_bytree` | 0.8 |
| `min_child_weight` | 50 |
| `reg_lambda` | 10 |
| `objective` | `reg:squarederror` |
| `tree_method` | `hist` |
| `random_state` | 42 |
| `n_jobs` | 실행 인자 `--threads`의 값, 기본값 4 |
| 검증 단계의 `n_estimators` | 최대 1000 |
| 검증 단계의 `eval_metric` | `mae` |
| 검증 단계의 `early_stopping_rounds` | 60 |
| 최종 학습의 `n_estimators` | 10시 모델 307개, 17시 모델 302개 |

검증 단계에서는 MAE를 기준으로 조기 종료한 뒤, 두 예보 시각의 예측을 평균한 그룹 모의 벌금으로 후보 설정을 선택했습니다. 최종 학습에는 검증 단계에서 선택한 트리 개수를 고정해 사용했습니다. 선택 기록은 `xgb_frozen_selection.json`에 있습니다.

G1/G2는 제공된 `current_group`의 A/B 배정을 유지했습니다. G1의 총 설비용량은 20,465.655kW, G2는 22,189.715kW입니다.

## 2. 완전 관측 178시간의 모의 벌금

세 모델은 동일한 178시간, 동일한 G1/G2 배정, 동일한 공통 채점기 `score_2024.py`로 평가했습니다. 이 문서의 기본 XGBoost(`xgb_basic`)는 팀원이 만든 XGBoost V1과 구별됩니다. 팀원 앙상블 V2는 XGBoost 25%와 LightGBM L1 75%를 결합한 모델의 저장된 예측 결과입니다.

벌금은 각 그룹에 대해 다음과 같이 계산한 후 G1과 G2의 값을 합산합니다.

`벌금 = 0.10 × Σ SMP(t) × k(t) × |그룹 예측 발전량(t) − 그룹 실제 발전량(t)|`

KST 기준 시각의 시(hour)가 11~15이면 k=3, 나머지는 k=1입니다. 발전소 하나라도 실제 발전량이 없으면 해당 시간 전체를 두 그룹의 벌금 계산에서 제외합니다. 실제로 관측된 0은 평가에 포함합니다.

완전 관측된 178시간은 2024-12-24 15:00부터 2025-01-01 00:00 KST까지입니다.

|모델|G1(원)|G2(원)|TOTAL(원)|기본 대비 감소율|
|---|---:|---:|---:|---:|
|기본 XGBoost (`xgb_basic`)|966,642.45|1,306,127.50|2,272,769.96|0.0000%|
|개선 XGBoost V1 (`xgb_improved_v1`)|829,799.54|1,170,476.09|2,000,275.63|11.9895%|
|팀원 앙상블 V2 (`team_ensemble_v2`)|943,511.92|1,260,114.52|2,203,626.44|3.0423%|

개선 XGBoost V1의 벌금은 기본 XGBoost보다 약 11.99%, 팀원 앙상블 V2보다 약 9.23% 낮습니다. 팀원 V2 대비 감소율은 팀원 V2의 벌금을 분모로 계산했습니다. 이 결과를 전체 연간 벌금의 감소율로 해석할 수는 없습니다.

## 3. 전체 유효 관측값의 발전소별 예측 오차

MAE·RMSE·WAPE는 178시간에 한정하지 않고, **2024년 전체의 유효한 발전소·시간 관측값 1,884,185개**로 계산했습니다. 세 모델에 동일한 관측 마스크를 적용하고, 실제 발전량이 없는 행은 제외했습니다. 실제로 관측된 0은 포함했습니다.

표의 지표는 발전소별 지표를 단순 평균한 값이 아니라, 모든 유효 발전소·시간 행의 오차를 모아 계산한 값입니다. 따라서 모든 발전소 각각에서 같은 모델이 우수하다는 의미는 아닙니다.

- **MAE(kWh)**: 예측 발전량과 실제 발전량의 절대오차 평균입니다.
- **RMSE(kWh)**: 제곱오차 평균의 제곱근입니다. 큰 오차에 더 민감합니다.
- **WAPE(%)**: 절대오차 합을 실제 발전량 합으로 나눈 뒤 100을 곱한 값입니다.
- **감소율(%)**: `100 × (기본 모델의 지표 − 비교 모델의 지표) / 기본 모델의 지표`입니다. 양수는 개선, 음수는 악화를 나타냅니다.

|모델|MAE(kWh)|RMSE(kWh)|WAPE(%)|MAE 감소율|RMSE 감소율|WAPE 감소율|
|---|---:|---:|---:|---:|---:|---:|
|기본 XGBoost (`xgb_basic`)|6.378152|21.223494|26.203964|0.0000%|0.0000%|0.0000%|
|개선 XGBoost V1 (`xgb_improved_v1`)|6.196805|20.726928|25.458921|2.8432%|2.3397%|2.8432%|
|팀원 앙상블 V2 (`team_ensemble_v2`)|6.015934|20.811957|24.715831|5.6790%|1.9391%|5.6790%|

MAE 열의 6.378152, 6.196805, 6.015934는 **평균 절대오차**를 나타냅니다. WAPE는 같은 관측 마스크와 실제 발전량 합을 사용하므로, 이번 비교에서는 기본 모델 대비 WAPE 감소율과 MAE 감소율이 같습니다.

## 4. 최종 모델 비교 결과

### 벌금 평가

- 개선 XGBoost V1은 기본 XGBoost 대비 벌금이 11.99% 감소했습니다.
- 팀원 앙상블 V2는 기본 XGBoost 대비 벌금이 3.04% 감소했습니다.
- 개선 XGBoost V1은 팀원 앙상블 V2보다 벌금이 약 9.23% 낮았습니다.

이 벌금 비교는 완전 관측된 **178시간**에 대한 결과입니다.

### 예측 오차 평가

- 개선 XGBoost V1은 기본 모델 대비 MAE 2.84%, RMSE 2.34%, WAPE 2.84% 감소했습니다.
- 팀원 앙상블 V2는 기본 모델 대비 MAE 5.68%, RMSE 1.94%, WAPE 5.68% 감소했습니다.

이 오차 비교는 전체 유효 관측값 **1,884,185개**에 대한 결과입니다.

### 종합 해석

세 모델 중 **개선 XGBoost V1은 총벌금과 RMSE에서**, **팀원 앙상블 V2는 MAE와 WAPE에서** 가장 우수했습니다.

그룹 벌금에는 그룹 내부 오차의 상쇄, 시간별 SMP와 k 가중치가 반영됩니다. 발전소별 MAE·RMSE·WAPE와 계산 단위 및 평가 표본이 다르므로 지표별 순위가 달라질 수 있습니다.

현재 평가에서 개선 XGBoost V1은 벌금 최소화에 유리했습니다. 다만 이 순위가 공식 대회의 전체 평가 기간에서도 유지되는지는 추가 검증이 필요합니다.

## 5. 파일 안내

| 파일 | 내용 |

`forecast.csv`의 기간은 2024-01-01 01:00부터 2025-01-01 00:00 KST까지입니다. 파일은 8,784시간 × 2그룹 = 17,568행으로 구성됩니다. 예측 발전량의 단위는 kWh이며, 벌금 결과는 `comparison.csv`에서 확인할 수 있습니다.

이 예측 파일은 2024년 로컬 평가용입니다. 공식 제출 기간과 다릅니다. 이 폴더에는 원본 학습 데이터, 실제 발전량, 발전소별 상세 예측과 학습된 모델 파일을 포함하지 않았습니다.

## 6. 실행 안내와 수치 확인 기준

제공 데이터를 별도로 준비하고 Python 환경에 numpy, pandas, pyarrow, lightgbm, xgboost, scikit-learn을 설치해야 합니다.

```sh
python xgboost_comparison.py --data DATA_FOLDER --out NEW_OUTPUT_FOLDER
python score_2024.py --data DATA_FOLDER --composition composition.csv --forecast forecast.csv --out NEW_SCORE.json
```

첫 번째 명령은 원본 학습·예측 코드를 실행하며, 두 번째 명령은 이 폴더에 저장된 그룹 배정과 예측 파일을 채점합니다. 라이브러리 버전에 따라 재실행 결과가 달라질 수 있습니다.

원본 학습 코드가 출력하는 일부 벌금은 부분 관측 발전소만 합산한 대리 평가 결과입니다. **이 문서와 `comparison.csv`에 제시된 178시간 벌금은 공통 채점기 `score_2024.py`의 결과를 기준으로 합니다.** 이 채점기는 로컬 모의 평가용이며 공식 서버 채점 코드가 아닙니다.

README의 벌금 표는 `comparison.csv`, 오차 표는 `metrics.csv`의 수치와 일치합니다. CSV의 계산 정밀도는 그대로 유지했습니다. 문서에서는 벌금을 소수 둘째 자리, 오차 지표를 소수 여섯째 자리, 표의 감소율을 소수 넷째 자리로 표시했습니다. 결론에 제시한 감소율은 소수 둘째 자리로 반올림했습니다.
