# 1차 개선 XGBoost: 저장된 2024년 예측과 평가

**2024년 전체 8,784시간 중 253개 발전소의 실제 발전량이 모두 있는 178시간만 모의 벌금 평가에 사용했습니다. 이 벌금은 전체 연간 벌금이나 공식 서버 점수가 아닙니다.**

원본 코드와 저장된 예측을 복사하고, 동일한 저장 예측으로 요청한 비교표를 계산했습니다. 재학습, 하이퍼파라미터 변경, 예측값 수정은 수행하지 않았습니다.

## 모델과 학습

xgboost_comparison.py는 총벌금 2,000,275.63원을 낸 xgb_improved를 학습·예측했던 원본 코드의 바이트 단위 복사본입니다. 원본에는 LightGBM 및 기본 XGBoost 비교 실행도 포함되어 있습니다. 이 폴더를 업로드하기 위해 코드를 다시 실행하지 않았습니다.

- 초기 학습: 2022년 제공 기상예보와 실제 발전량.
- 설정 및 조기 종료 선택: 2023년 검증 자료만 사용. 최종 학습: 2022~2023년.
- 라운드별 최종 학습 마감: 2023-12-31 10:00 및 17:00 KST. 각 발행 시각 이전 정보만 사용.
- 하루 전 10시·17시 예보를 각각 학습하고 예측 발전량을 평균.
- 설비이용률(발전량/설비용량, 학습 타깃 [0,1.2]) 예측 후 설비용량을 곱함. 야간 0, 비음수 출력.
- 추가 특징: 발전소 코드, 제공사 간 구름·온도 차이, 온도−이슬점, 태양위치와 구름·UV의 상호작용, B 풍속 m/s 환산 특징.
- 선택 설정: max_depth=6, learning_rate=0.03, subsample=0.8, colsample_bytree=0.8, min_child_weight=50, reg_lambda=10, seed=42. 10시 모델 307개, 17시 모델 302개 트리.
- G1/G2: 제공 current_group A/B 유지. 각 용량은 20,465.655kW / 22,189.715kW.
- 2024년 실제 발전량은 최종 평가에만 사용. 2024년 평가 결과로 재튜닝하지 않음.

## 벌금 비교

세 모델 모두 같은 178시간, 같은 G1/G2, 같은 원본 score_2024.py로 계산했습니다. 이때 기본 XGBoost는 xgb_basic이며 팀원의 XGBoost V1과 다른 모델입니다. 팀원 앙상블 V2는 XGBoost 25% + LightGBM L1 75%를 저장 예측으로 재현한 결과입니다.

`벌금 = 0.10 × Σ SMP(t) × k(t) × |그룹 예측(t) − 그룹 실제(t)|`

11~15시 k=3, 나머지 k=1. 실제 발전량이 하나라도 결측인 시간은 벌금 계산에서 통째로 제외합니다. 결측을 0이나 예측값으로 채우지 않습니다. 실제로 관측된 0은 포함합니다. 완전 관측 구간은 2024-12-24 15:00 ~ 2025-01-01 00:00 KST입니다.

|모델|G1(원)|G2(원)|TOTAL(원)|기본 대비 감소율|
|---|---:|---:|---:|---:|
|xgb_basic|966,642.45|1,306,127.50|2,272,769.96|0.0000%|
|xgb_improved_v1|829,799.54|1,170,476.09|2,000,275.63|11.9895%|
|team_ensemble_v2|943,511.92|1,260,114.52|2,203,626.44|3.0423%|

1차 개선 모델은 기본보다 약 11.99%, 팀원 앙상블 V2보다 약 9.23% 벌금이 낮습니다. 차이는 이 178시간에서의 결과이며 연간 전체 성능으로 일반화할 수 없습니다.

## 오차 지표

전체 유효 관측 1,884,185개 발전소·시간을 동일 마스크로 평가했습니다. 발전소별 지표의 단순 평균이 아닌 관측 행 전체를 모은 지표입니다. 실제 발전량 결측은 제외하고 관측된 0은 포함합니다.

- MAE(kWh): 평균 절대오차. RMSE(kWh): 평균 제곱오차의 제곱근.
- WAPE(%): 100 × 절대오차 합 / 실제 발전량 합.
- 감소율(%): 100 × (기본 모델 지표 − 해당 모델 지표) / 기본 모델 지표. 양수는 개선, 음수는 악화.

|모델|MAE(kWh)|RMSE(kWh)|WAPE(%)|MAE 감소율|RMSE 감소율|WAPE 감소율|
|---|---:|---:|---:|---:|---:|---:|
|xgb_basic|6.378152|21.223494|26.203964|0.0000%|0.0000%|0.0000%|
|xgb_improved_v1|6.196805|20.726928|25.458921|2.8432%|2.3397%|2.8432%|
|team_ensemble_v2|6.015934|20.811957|24.715831|5.6790%|1.9391%|5.6790%|

## 파일

- xgboost_comparison.py: 원본 학습·예측 코드.
- comparison.csv: 공통 178시간의 G1/G2/TOTAL 벌금 비교 및 기본 대비 감소액·감소율.
- metrics.csv: 전체 유효 관측의 MAE/RMSE/WAPE 및 기본 대비 감소율.
- composition.csv: 1차 개선 모델의 253개 발전소 그룹 배정 원본 복사.
- forecast.csv: 1차 개선 모델의 연간 그룹 예측 원본 복사. **예측 발전량(kWh)이며 벌금 파일이 아닙니다.**
- xgb_frozen_selection.json: 당시 2023년 검증 선택 및 트리 개수 기록.
- score_2024.py: 팀원 공통 로컬 모의 채점기 원본. 공식 서버 채점 코드로 간주하지 않습니다.
- provenance.json: 원본 출처와 바이트 단위 동일성 확인용 SHA256.

forecast.csv는 2024-01-01 01:00 ~ 2025-01-01 00:00 KST, 8,784시간 × 2그룹 = 17,568행입니다. 2024년 테스트용이며 공식 제출 기간과 다릅니다. 원본 학습 데이터, 실제 발전량, 발전소별 상세 예측, 학습된 모델 파일은 이 폴더에 포함하지 않았습니다. 요청에 따라 그룹 배정 및 그룹 예측 CSV를 공개합니다.

## 실행 안내

제공 데이터를 별도로 확보하고 Python 환경에 numpy, pandas, pyarrow, lightgbm, xgboost, scikit-learn을 설치해야 합니다. 원본 코드의 실행 예시는 다음과 같습니다. 재실행 결과는 라이브러리 버전에 영향을 받을 수 있습니다.

```sh
python xgboost_comparison.py --data DATA_FOLDER --out NEW_OUTPUT_FOLDER
python score_2024.py --data DATA_FOLDER --composition composition.csv --forecast forecast.csv --out NEW_SCORE.json
```

원본 코드 자체가 출력하는 일부 벌금은 부분 관측 발전소만 합산한 관측 구간 대리 벌금입니다. **이 README와 comparison.csv의 178시간 벌금은 반드시 score_2024.py 결과를 기준으로 해석해야 합니다.**
