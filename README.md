# 2024년 발전량·벌금 비교

## 실행

Python 3.12 환경에서 `pip install -r requirements.txt` 후 실행합니다.

```powershell
python improved.py --data "압축을 푼 폴더/01_participant_dataset" --out results
```

`baseline.py`를 `improved.py`와 같은 폴더에 두세요. 원본 baseline 파일은 수정하지 않았습니다. 이번 실험은 improved.py 안에서 기본 모델을 재현하며, 양쪽 모두 재현성을 위해 random_state=42를 사용합니다.

## 비교 설계

- 최종 학습: 2022~2023년 발전량과 당시 하루 전 예보. 실제 기상 관측값은 입력하지 않습니다.
- 설정 선택: 2022년 학습 / 2023년 검증. 세 설정의 G1/G2 합산 벌금으로 선택합니다. 조기 종료는 발전소 설비이용률 MAE를 사용합니다.
- 최종 평가: 2024년. 설정 선택에 사용하지 않습니다.
- 시간은 KST, 우측닫힘입니다. 2024년 평가 구간은 2024-01-01 01:00부터 2025-01-01 00:00까지입니다.
- 기본 모델: 600 trees, learning_rate=0.06, num_leaves=127.
- 개선 모델: 31/63/127 leaves, learning_rate=0.05/0.03/0.03, 최대 1000 trees, 60회 조기 종료. 제공사 간 예보 차이, 기온-이슬점 차이, 태양고도와 구름량·UV의 상호작용, 발전소 ID 등을 추가합니다.
- 양쪽 모두 10시·17시 예보 모델을 평균하고 야간 예측은 0으로 처리합니다.
- 학습 기간은 요청에 맞춰 양쪽 모두 2022~2023년으로 고정합니다. 이번 실험에서는 3년 학습이나 그룹 재배정을 탐색하지 않습니다.

## 용량 조건

데이터 README에는 그룹당 최소 20,000kW로 적혀 있습니다. 사용자가 언급한 2,000kW보다 강한 조건이며 기본 배정은 두 조건 모두 충족합니다. G1=20,465.655kW, G2=22,189.715kW입니다.

## 벌금과 결측 처리

`벌금 = 0.10 × Σ(SMP × k × |그룹 예측합 - 그룹 실적합|)`

k는 타임스탬프의 시가 11~15일 때 3, 나머지는 1입니다. 기본·개선 모델에 동일한 실제 SMP와 가중치를 사용합니다. 이들은 모델 입력이 아닌 사후 평가에만 사용됩니다.

발전량 데이터는 2022년 80개, 2023년 148개, 2024년 253개 발전소에 기록이 있습니다. 기록이 없는 발전소·시각은 0으로 가정하지 않고 예측과 실적 양쪽에서 제외합니다. 따라서 총액은 **관측된 발전소·시간에 한정된 가상 정산 벌금**이며 전체 253개소의 완전한 연간 벌금이나 대회 공식 점수로 해석하면 안 됩니다. 모든 구성원이 관측된 그룹·시간 수와 그 구간 벌금도 report.json에 별도 저장합니다.

## 결과 파일

- report.json: 선택 설정, 검증 결과, 2024년 벌금 감소액·비율, 관측 범위
- baseline_2024_groups.csv / improved_2024_groups.csv: 시간별 실제·예측 발전량, 관측 발전소 수, 벌금
- composition.csv: 동일하게 유지한 발전소 그룹 배정
- *_round*.txt: 최종 학습 모델
